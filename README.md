# Hermes Telegram Bot (Agent AI)

دستیار هوشمند تلگرام هرمس برای احمد رحیمی، متصل به هوش مصنوعی گوگل (Gemini 3.5 Flash).

## قابلیت‌ها
- اتصال مستقیم به هوش مصنوعی قدرتمند Google Gemini 3.5 Flash
- پاسخ‌گویی سریع، دقیق و با لحن هوشمندانه به زبان فارسی
- پاسخ به سوالات برنامه‌نویسی، روزمره و تخصصی
- کاملاً امن و اختصاصی برای احمد رحیمی (`chat_id: 1015253171`)
- قابلیت کارکرد ۲۴ ساعته ابری بدون نیاز به سیستم روشن یا فیلترشکن

## استقرار ابری (Cloud Deploy)
برای استقرار رایگان و ۲۴ ساعته روی سرویس‌های ابری، متغیرهای محیطی زیر را تنظیم کنید:

- `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام
- `GEMINI_API_KEY`: کلید API گوگل جمینای
- `TELEGRAM_ALLOWED_USERS`: شناسه کاربری احمد رحیمی (`1015253171`)
